Project workflow

From SEC Filings to Model Output

01Extract

Read SEC `num.txt` and `sub.txt` XBRL financial statement files.

02Engineer

Create ROA, debt ratio, cost structure, size, asset turnover, profit margin, and growth features.

03Clean

Drop invalid values and filter ratios to build a clean panel dataset of 21,087 rows.

04Model

Compare fixed effects panel regression with Random Forest regression for interpretability and prediction.
