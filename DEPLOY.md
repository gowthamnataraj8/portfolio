# Deploy Your Portfolio Live

This project is a static website for Gowtham Nataraj's data analyst portfolio, so you can upload it without a backend. The easiest options are GitHub Pages, Netlify, or Vercel.

## Best Option For Interviews: Netlify

1. Go to `https://app.netlify.com/drop`.
2. Drag and drop this full project folder into the page.
3. Netlify will give you a live website link.
4. Open the link and check `index.html`, `dashboard.html`, and `products.html`.
5. Copy that live link into your resume, LinkedIn, GitHub profile, or job applications.

Use this if you want the fastest live demo.

## Good Portfolio Option: GitHub Pages

1. Create a GitHub account if you do not already have one.
2. Create a new repository, for example:

```text
financial-analytics-portfolio
```

3. Upload all project files:

```text
index.html
dashboard.html
products.html
about.html
contact.html
login.html
style.css
script.js
README.md
data/
assets/
projects/
Google_certificate.png
gowtham-nataraj-profile.jpeg
gowtham-nataraj-resume.pdf
```

4. In GitHub, open the repository settings.
5. Go to `Pages`.
6. Under `Build and deployment`, choose:

```text
Source: Deploy from a branch
Branch: main
Folder: /root
```

7. Save it.
8. Wait a few minutes. GitHub will show your live website link.

Your live link will look similar to:

```text
https://gowthamnataraj8.github.io/financial-analytics-portfolio/
```

## Before Sending To Recruiters

Check these items:

- The homepage opens without login.
- KPI cards load correctly.
- Charts are visible.
- Export buttons work.
- Case studies page opens.
- Your README explains the project clearly.
- Your resume or LinkedIn includes the live link.
