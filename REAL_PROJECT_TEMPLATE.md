# Real Project Template

Use this structure when you add real portfolio projects to `script.js`.

```js
{
  name: "Project Name",
  focus: "Dashboard",
  problem: "What business question did the project answer?",
  tools: ["SQL", "Python", "Power BI"],
  impact: 90,
  status: "Ready",
  dataset: "Dataset name or source",
  role: "What you personally did",
  outcome: "What insight or decision the project supported",
  links: [
    { label: "GitHub", url: "https://github.com/..." },
    { label: "Live Demo", url: "https://..." },
    { label: "Screenshot", url: "assets/powerbi/dashboard-page-1.png" },
    { label: "Download File", url: "assets/powerbi/report.pbix" }
  ],
  summary: "Short project summary for recruiters."
}
```

- UK job market analysis dashboard
- Sales performance dashboard
- Customer segmentation analysis
- Financial KPI dashboard
- Excel monthly reporting pack
